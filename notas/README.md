# Carpeta de salida de notas

Aquí vive la **app del docente** (`index.html`) y aquí se guardan los archivos de notas.

## Uso

1. Abra `index.html` (a través de la URL de GitHub Pages: `.../notas/`).
2. Cargue los comprobantes `.json` que enviaron los estudiantes.
3. Exporte y guarde en esta misma carpeta:
   - `notas_participacion.csv` — nota de cada estudiante (2,5 %).
   - `coevaluacion_por_grupo.csv` — promedio recibido por cada pódcast (informa el 5 %).

El procesamiento ocurre por completo en su navegador; no se envía nada a internet.
